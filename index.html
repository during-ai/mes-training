MES 작업 안내

상황을 골라서 보세요. (현장 작업자용)

작업자 가동

작업자 눌러 본인 선택 → 가동(시작) 확정.

이것부터! 작업자 가동을 안 하면 시작·양품·인쇄가 모두 잠깁니다.

자재 투입 (스캔)

투입 → 무인Lot입력 창에서 BOM 자재를 로트 바코드로 스캔 → 저장.

품번(숫자)만 스캔 ✗ — 라벨의 큰 바코드(로트)를 스캔하세요.

시작

시작 누르면 작업이 가동 됩니다.

양품 등록

양품 눌러 만든 수량 입력. 진행률(%)이 올라갑니다. (불량은 불량)

제품 라벨 인쇄

인쇄 → 인쇄 수량 입력 → 저장/인쇄.

양품을 먼저 등록해야 인쇄됩니다. (총작업수량 0이면 인쇄 안 됨)

지시 수량을 다 채우면 종료 눌러 작업을 마감합니다.

잠깐 멈출 땐 보류, 설비 정지 사유는 비가동 이력에 등록.

“창고에 존재하지 않는 바코드”

자재가 라인 창고(권선)에 없음. 이동전표를 인수(수령) 했는지 확인, 또는 재고 담당 문의. 품번만 스캔한 경우도 이 오류 → 로트 바코드로 스캔.

“BOM에 없습니다”

이 작업지시의 자재가 아님. 화면 BOM 목록에 있는 자재만 투입.

스캔하면 “삑” 소리만 나고 안 들어감

① 입력칸 클릭(커서 확인) → ② 한/영 영문으로 → ③ 스캐너 USB 케이블 재장착/교체 → ④ 안 되면 설비담당 요청.

양품 · 인쇄 버튼이 안 눌림

작업자 가동 → 시작을 먼저 하세요. 인쇄는 양품 등록 후 됩니다.

창고용도
SL004권선(생산3팀) — 라인 투입
SL301원자재창고 — 입고·보관
로트 형식예시
구매품 (C…)C9046321200024-2609016101
생산품 (TD…)TD20260904D011-0010
바코드는 Code39로 출력해야 스캐너가 읽습니다. 인쇄는 배율 100%(축소 금지).

창고 이동 = 2단계
① 출고(이동전표 생성) → ② 인수(라인에서 수령확인). 인수해야 라인 창고에 잡혀 투입됩니다.
